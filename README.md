# Bus Position Solution (BPS) - Frontend

Bus Position Solution (BPS) হল একটি ওয়েব-ভিত্তিক অ্যাপ্লিকেশন, যা বাস ট্রিপের অবস্থান, রুটের তথ্য, টিপসের হিসাব এবং সংশ্লিষ্ট রিপোর্টগুলো দক্ষতার সাথে পরিচালনা করতে ব্যবহৃত হয়। এটি BPS অ্যাপ্লিকেশনের Angular ফ্রন্টএন্ড অংশ।

---

## 🚀 Key Features

* 📍 **Trip Management:** বাস ট্রিপ এবং চলাচলের তথ্য প্রদর্শন ও আপডেট।
* 🗺️ **Place & Route Management:** বিভিন্ন স্থান এবং রুট যুক্ত ও পরিচালনা করার সুবিধা।
* 💰 **Tip Calculations & Reports:** বাসের টিপস এবং আর্থিক রিপোর্টিংয়ের বিস্তারিত ভিউ।
* 📊 **Dynamic Data Grids:** কাস্টম ফিল্টারিং, সর্টিং এবং কলাম সাজানোর সুবিধা।
* 📄 **PDF Export:** রিপোর্ট এবং সামারি PDF আকারে ডাউনলোডের সুবিধা।

---

## 🛠️ Tech Stack

* **Framework:** Angular (v16+)
* **Language:** TypeScript, HTML5, CSS3/SCSS
* **UI Components & Styling:** Bootstrap, RxJS
* **Architecture:** Component-based UI with Services Architecture
