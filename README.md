# Bus Position Solution (BPS) - Frontend

**Bus Position Solution (BPS)** is a web application designed to streamline and manage bus trip logistics, route tracking, tip calculations, and comprehensive operational reporting. This repository contains the Angular frontend codebase for the BPS platform.

---

## 🚀 Key Features

* 📍 **Trip Management:** Track, record, and manage bus trip details efficiently.
* 🗺️ **Place & Route Management:** Configure and maintain locations, routes, and geographic data.
* 💰 **Tip Calculations & Financials:** Automate tip records and driver performance analytics.
* 📊 **Dynamic Data Grids:** Advanced data tables with sorting, filtering, and customizable column visibility.
* 📄 **PDF Exporting:** Generate and export trip reports and summaries directly into PDF format.

---

## 🛠️ Tech Stack

* **Framework:** Angular (v16+)
* **Language:** TypeScript, HTML5, SCSS/CSS
* **UI & Styling:** Bootstrap, RxJS
* **Architecture:** Component-driven design integrated with Angular Services

---

## 🧰 Prerequisites

Ensure you have the following installed on your local development machine:

* [Node.js](https://nodejs.org/) (v18.x or higher)
* [npm](https://www.npmjs.com/) (Node Package Manager)
* [Angular CLI](https://angular.io/cli) (`npm install -g @angular/cli`)
